## 🆕 Ajouts demandés par l'auteur (2026-11-08) — rôles officiels Thiercelieux

L'auteur a demandé d'ajouter 5 rôles **en se référant aux règles officielles** :
`Enfant Sauvage` · `Cupidon` · `Servante Dévouée` · `Renard` · `Grand Méchant Loup`

| Rôle | Règle officielle retenue | Source |
|---|---|---|
| **Cupidon** | 1ʳᵉ nuit, désigne 2 amoureux (peut se désigner). Si l'un meurt, l'autre meurt de chagrin. Interdit de voter contre son aimé. Couple mixte loup+villageois = 3ᵉ camp qui doit rester seul. | livret Lui-même |
| **Enfant Sauvage** | Villageois. 1ʳᵉ nuit il désigne un modèle. Si le modèle est éliminé, il devient Loup-Garou pour le reste de la partie. | ext. Personnages |
| **Servante Dévouée** | Avant révélation de la carte du joueur éliminé **par le vote**, elle peut se révéler, perdre sa carte et endosser le rôle de l'éliminé (pouvoirs réinitialisés). Inactive si elle est amoureuse. | ext. Personnages |
| **Renard** | Chaque nuit il désigne un joueur ; le meneur vérifie **ce joueur + ses 2 voisins**. Au moins 1 loup → il garde son pouvoir. Aucun loup → il perd son pouvoir définitivement. | ext. Personnages |
| **Grand Méchant Loup** | Dévore avec les loups, puis se réveille **seul** pour une 2ᵉ victime, **tant qu'aucun loup (ni Enfant Sauvage devenu loup) n'est mort**. Ne peut pas dévorer un loup. | ext. Personnages |

## ✅ Arbitrages donnés par l'auteur (2026-11-08)

| Point | Décision |
|---|---|
| Loup Rouge | ne peut pas bloquer la même personne 2 nuits consécutives · **peut** bloquer un loup |
| Loup Père Infecte | infecte **1 seule fois** dans la partie |
| Loup Noir | le narrateur **n'annonce pas** le nom du joueur muté — c'est discret |
| Villageois simple | **ajouté** |
| Salvateur | **peut** se protéger lui-même · pas la même personne 2 nuits de suite |
| Ancien Sage | 2 morsures **sur des nuits séparées** suffisent à le tuer |
| Détective | les joueurs solo sont **ennemis de tous** · Alien ennemi de : villageois, loups, pyromane, amoureux · Amoureux ennemis des villageois |
| Ours | voisins vivants immédiats (gauche/droite) |
| Corbeau | **+2 voix** · camp **village** |
| Berger | nombre de moutons **fixé par le narrateur** au début · quand il les a tous utilisés il devient **Villageois** |
| Barbier | **1 seule fois** · s'il tue un joueur **solo**, il **survit** |
